## 📌 Tentang Proyek Ini

Repository ini berisi **portofolio interaktif 3D** untuk **Rey** — seorang Fullstack Developer, 3D Engineer, dan AI Jailbreaker. Dibangun dengan **Three.js** untuk latar belakang 3D yang halus, serta dilengkapi dengan berbagai fitur modern seperti:

- Skill bars animasi
- Dashboard stats
- Project cards dengan modal detail
- Testimoni
- Dark/Light mode toggle
- Dan banyak lagi

---

## ✨ Fitur Unggulan

| Fitur | Keterangan |
|-------|------------|
| ✅ **Background 3D Interaktif** | Menggunakan Three.js dengan objek Icosahedron, partikel, dan ring orbit |
| ✅ **Skill Bars Animasi** | Persentase skill yang muncul saat scroll |
| ✅ **Dashboard Stats** | Menampilkan project selesai, klien, kepuasan, dll |
| ✅ **Layanan & Testimoni** | Section profesional untuk meyakinkan klien |

| ✅ **Tools & Teknologi** | Daftar lengkap tools yang dikuasai |

| ✅ **Project Modal** | Klik project card untuk melihat detail lengkap |
