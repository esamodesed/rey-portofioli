## 📌 Tentang Proyek Ini

Repository ini berisi **portofolio interaktif 3D** untuk **Rey** — seorang Fullstack Developer, 3D Engineer, dan AI Jailbreaker. Dibangun dengan **Three.js** untuk latar belakang 3D yang halus, serta dilengkapi dengan berbagai fitur modern.

## ✨ Fitur Unggulan

| 🎯 Fitur | 📝 Keterangan |
|----------|---------------|
| 🎨 **Background 3D Interaktif** | Menggunakan Three.js dengan objek Icosahedron, partikel, dan ring orbit |
| 📊 **Skill Bars Animasi** | Persentase skill yang muncul saat scroll |
| 📈 **Dashboard Stats** | Menampilkan project selesai, klien, kepuasan, dll |
| 💼 **Layanan & Testimoni** | Section profesional untuk meyakinkan klien |
| ⏳ **Timeline Perjalanan** | Riwayat karir dari 2020 hingga 2025 |
| 🛠️ **Tools & Teknologi** | Daftar lengkap tools yang dikuasai |
| 📰 **Blog Preview** | Artikel terbaru tentang AI, 3D, dan Security |
| ❓ **FAQ** | Menjawab pertanyaan umum klien |
| 📬 **Kontak & Form** | Telegram, WhatsApp, Email, dan form pesan |
| 🔍 **Project Modal** | Klik project card untuk melihat detail lengkap |
| 🌓 **Dark/Light Mode** | Toggle tema gelap dan terang |
| ⏳ **Preloader & Custom Cursor** | Pengalaman loading yang halus dan cursor kustom |
| ⌨️ **Typing Effect** | Teks berganti otomatis di hero section |
| 📱 **Responsive** | Mobile friendly, tampilan optimal di semua device |
